# Prefix implementation convention — before reacting outcomes

“Through observation 144” in NATIVE_PLAN.md means call each policy at
observations 0 through 144, recording the public shops immediately before
the call at 144. This includes the first route decision, so its activation
telemetry can be verified. Applying these 145 actions leaves observation
145 and 146 stored frames; it is still a nonterminal prefix of the unchanged
720-frame configuration. Fast and original-framework checks use exactly
this same boundary and no terminal reward is stored.

The convention changes no seed range, eligibility condition, route choice,
sample count, strength gate or confidence rule. Its hash is bound into the
new native receipts together with NATIVE_PLAN.md and QUALIFICATION_SCOPE.md.
