and observed-hire research. They perform local native games only, with no
network/submission operation. They refuse to run without the exact passing
independent confirmation receipts. They do not promote main automatically.

After confirmation passes, run the corresponding profile:

```powershell
python -X utf8 diagnostics\native_preservation_20260928\public_wins.py public-loss --workers 3
python -X utf8 diagnostics\native_preservation_20260928\loader.py public-loss
```

Use `observed-hire` instead for the observed-recovery study. Only candidates
passing its separate confirmation gates enter public-win preservation.

seats are checked. Only exact hash/seed/seat/tape native rows are reused.

through direct and actual Kaggle local file loading. Each policy gets two
fixtures in both seats, including its repaired behavior. Timing, overage,
entrypoint and policy errors are recorded. Failed parity records retain
actions for diagnosis. No new strength claim follows from these gates.
